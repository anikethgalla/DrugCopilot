## ⚠️ Medical Safety & Research Disclaimer

> **IMPORTANT**: Drug repurposing hypotheses generated by this system are **computational research findings** and are **NOT medical advice or evidence of clinical efficacy**.  
> This system never claims *"This drug cures disease X"*. Instead, it produces explainable, evidence-backed biological hypotheses derived from verified public biomedical data.

## 🌟 Key Features

1. **Zero Synthetic Biomedical Data**:
   - Every drug, protein, disease, clinical trial, and literature reference originates from live public databases:
     - **ChEMBL** (EMBL-EBI): Bioactivity, IC50/Ki, drug mechanisms, approved/investigational indications.
     - **Open Targets Platform**: Disease-target genetic associations, GWAS credible sets, L2G causal scores.
     - **UniProtKB**: Curated human protein sequences, functional domains, and Reactome pathways.
     - **NCBI PubChem**: Canonical/Isomeric SMILES, molecular weights, and CIDs.
     - **ClinicalTrials.gov**: Real human clinical studies, NCT identifiers, recruitment phases, and sponsors.
     - **PubMed / NCBI E-Utilities**: Peer-reviewed scientific publications and co-mention citations.

2. **Neo4j Central Knowledge Graph**:
   - Unique canonical constraints on `Drug.canonical_id`, `Disease.canonical_id`, `Protein.uniprot_id`, `Gene.ensembl_id`, `ClinicalTrial.nct_id`, and `Publication.pmid`.
   - Rich relational graph connecting `Drug -[:TARGETS]-> Protein`, `Gene -[:ENCODES]-> Protein`, `Gene -[:ASSOCIATED_WITH]-> Disease`, `Protein -[:PARTICIPATES_IN]-> Pathway`, `Disease -[:INVOLVES]-> Pathway`, `Drug -[:TREATS]-> Disease`, `Drug -[:INVESTIGATED_IN]-> ClinicalTrial`, and `Drug -[:MENTIONED_IN]-> Publication`.

3. **Multi-Strategy Graph Repurposing Engine**:
   - **Direct Target Overlap**: Traverses Disease $\leftarrow$ Gene $\rightarrow$ Protein $\leftarrow$ Drug.
   - **Shared Pathway Co-occurrence**: Traverses Disease $\rightarrow$ Pathway $\leftarrow$ Protein $\leftarrow$ Drug.
   - **PPI 2-Hop Network Proximity**: Traverses Protein-Protein Interaction neighborhoods.
   - **Indication Pivot**: Traverses approved therapies for related target profiles.

4. **Explainable Numerical Scoring**:
   - Transparent scoring breakdown with mathematical derivations:
     $$\text{Overall Score} = 0.30 \cdot S_{\text{target}} + 0.20 \cdot S_{\text{pathway}} + 0.20 \cdot S_{\text{network}} + 0.15 \cdot S_{\text{clinical}} + 0.10 \cdot S_{\text{pub}} + 0.05 \cdot S_{\text{genetic}}$$
   - Rigorous 5-tier classification: *Established evidence*, *Strong computational evidence*, *Moderate computational evidence*, *Weak evidence*, *Hypothesis*.

5. **AI Copilot with Controlled Read-Only Tools**:
   - Autonomous tool calling with AST Cypher write prevention (blocks `CREATE`, `MERGE`, `DELETE`, `DROP`, `SET`).
   - Generates biological reasoning paths, multi-modal evidence citations, and scientific limitation disclosures.

6. **Interactive Cytoscape.js Workspace**:
   - Real-time ego-subgraph extraction with dynamic force-directed, concentric, and hierarchical layouts.
   - One-click node expansion and edge provenance popover with official database URLs.

## 🚀 Quick Start

### 1. Prerequisites
- **Python 3.11+**
- **Node.js 18+** & **npm**
- **Docker & Docker Compose** (optional for containerized run)

### 2. Environment Configuration
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

Set your optional OpenAI API key in `.env` if you wish to use OpenAI models (the Copilot will automatically use its internal graph reasoning engine if no key is provided):
```ini
OPENAI_API_KEY=sk-...
```

### 3. Docker Compose (Full Stack)
Run the entire platform (Neo4j, Redis, FastAPI Backend, Background Worker, Next.js Frontend) with a single command:
```bash
docker compose up -d
```
- Frontend: [http://localhost:3000](http://localhost:3000)
- Backend API Docs: [http://localhost:8000/docs](http://localhost:8000/docs)
- Neo4j Browser: [http://localhost:7474](http://localhost:7474) (Username: `neo4j`, Password: `biomedical_graph_password_2025`)

---

### 4. Local Development

#### Backend
```bash
cd backend
python -m venv venv
# On Windows PowerShell:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt

# Run initial biomedical data bootstrap
python -m app.ingestion.bootstrap

# Start FastAPI server
uvicorn app.main:app --reload --port 8000
```

#### Frontend
```bash
cd frontend
npm install
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000).
